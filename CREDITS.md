# Источники

Заполняется по ходу работы: каждую библиотеку, шрифт, запись и API добавляем сюда в том же PR, где они появились.

- StPageFlip (page-flip 2.0.7) — MIT. [Исходный код и лицензия](https://github.com/Nodlik/StPageFlip)
- Dexie — Apache-2.0

- Vitest, Playwright — MIT / Apache-2.0

## Музыка

- Фрагменты песен: iTunes Search API, provided courtesy of iTunes. Звучат потоком, в репозитории и в экспорте не хранятся.
- Свободные записи: только CC0 или CC BY, без NC. Указывать автора, название, источник и лицензию.

## Шрифты

- Literata, IBM Plex Mono — SIL Open Font License 1.1 (когда подключим).

- Caveat — SIL Open Font License 1.1. Локальные кириллический и латинский наборы. [Fontsource](https://fontsource.org/fonts/caveat)
- Neucha — SIL Open Font License 1.1. Кириллица и латиница для записей гелевой ручкой на развороте 047. [Fontsource](https://fontsource.org/fonts/neucha)

## Материалы скетчбука

- Вырезки разворота 047 в `public/scraps/047` созданы для проекта в ImageGen. Бумагу, билеты, крепления, наклейки, след кружки и рисунки ручкой вырезали из двух листов материалов. Наборный заголовок и металлическая пружина созданы отдельно. У всех вырезок сохранён прозрачный фон. Фотополоска собрана из трёх фрагментов демо-снимка перрона.

- Бумага и скотч — тонированные производные карты высот Paper 001 (ambientCG, CC0). [Источник](https://ambientcg.com/view?id=Paper001)
- Переплёт и стол — тонированные diffuse-карты Denim Fabric и Plywood (Poly Haven, CC0). [Ткань](https://polyhaven.com/a/denim_fabric) · [Фанера](https://polyhaven.com/a/plywood) · [Лицензия](https://polyhaven.com/license)
- Билеты, почтовые оттиски и линейные рисунки в src/render/stickers — исходные SVG проекта. Иллюстрированные наклейки в public/stickers созданы специально для проекта с помощью ImageGen.
- Четыре иллюстративных демо-кадра WebP созданы специально для проекта с помощью ImageGen. Сцены вымышлены. Даты, города и время сюжетов выбраны для демонстрации. Погодные значения получены из почасовых данных Open-Meteo.

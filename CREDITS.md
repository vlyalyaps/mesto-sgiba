# Источники

Заполняется по ходу работы: каждую библиотеку, шрифт, запись и API добавляем сюда в том же PR, где они появились.

## Библиотеки

- React, Vite, TypeScript — MIT / Apache-2.0
- Dexie — Apache-2.0
- fflate — MIT
- web-audio-beat-detector — MIT
- Vitest, Playwright — MIT / Apache-2.0

## Музыка

- Фрагменты песен: iTunes Search API, provided courtesy of iTunes. Звучат потоком, в репозитории и в экспорте не хранятся.
- Свободные записи: только CC0 или CC BY, без NC. Указывать автора, название, источник и лицензию.

## Шрифты

- Literata, IBM Plex Mono — SIL Open Font License 1.1 (когда подключим).

## Изображения

- public/demo/photos — собственные SVG-заглушки проекта для контрольных дней. Настоящие фото демо-дней добавляем только с согласия людей на снимках.

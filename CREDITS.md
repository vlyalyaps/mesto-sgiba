# Источники

Заполняется по ходу работы: каждую библиотеку, шрифт, запись и API добавляем сюда в том же PR, где они появились.

## Музыка

- Фрагменты песен: iTunes Search API, provided courtesy of iTunes. Звучат потоком, в репозитории и в экспорте не хранятся.
- Свободные записи: только CC0 или CC BY, без NC. Указывать автора, название, источник и лицензию.

## Шрифты

- Literata, IBM Plex Mono, Golos Text — SIL Open Font License 1.1, локально через Fontsource.

- Caveat — SIL Open Font License 1.1. Локальные кириллический и латинский наборы. [Fontsource](https://fontsource.org/fonts/caveat)
- Neucha — SIL Open Font License 1.1. Кириллица и латиница для записей гелевой ручкой на развороте 047. [Fontsource](https://fontsource.org/fonts/neucha)

## Материалы скетчбука

- Кармашек, складная бумага, заметка с отогнутым краем, калька, засушенные растения, уголки, вырезка и следы в `public/scraps/life` созданы для проекта в ImageGen. Все вырезки сохранены как прозрачные WebP.

- Пять музыкальных носителей без логотипов и карта тропы в `public/scraps/materials` созданы для проекта в ImageGen. Подписи и шкалы долей накладываются на вырезки из данных записи.

- Вырезки разворота 047 в `public/scraps/047` созданы для проекта в ImageGen. С листов материалов сняты бумага, билеты, чек, крепления, след кружки и рисунки ручкой. Одна проволочная дуга с двумя пробитыми отверстиями повторяется поперёк сгиба.
- Одиннадцать образцов бумаги и ленты для заголовков созданы для проекта в ImageGen. На них напечатаны глифы Literata, Golos Text, IBM Plex Mono и Caveat (SIL Open Font License 1.1). В `public/letters` хранятся отдельные прозрачные WebP для 33 прописных и 33 строчных русских букв каждого набора. Исходные материалы и сценарий печати — в `scripts/letterpress`.

- Бумага и скотч — тонированные производные карты высот Paper 001 (ambientCG, CC0). [Источник](https://ambientcg.com/view?id=Paper001)
- Переплёт и стол — тонированные diffuse-карты Denim Fabric и Plywood (Poly Haven, CC0). [Ткань](https://polyhaven.com/a/denim_fabric) · [Фанера](https://polyhaven.com/a/plywood) · [Лицензия](https://polyhaven.com/license)
- Билеты, почтовые оттиски и линейные рисунки в src/render/stickers — исходные SVG проекта. Иллюстрированные наклейки в public/stickers созданы специально для проекта с помощью ImageGen.
- Четыре иллюстративных демо-кадра WebP созданы специально для проекта с помощью ImageGen. Сцены вымышлены. Даты, города и время сюжетов выбраны для демонстрации. Погодные значения получены из почасовых данных Open-Meteo.
- Сезонные стикеры в `src/assets/local/seasons` — Designed by [Freepik](https://www.freepik.com), лицензия приобретена командой. Листы разрезаны на отдельные стикеры, фон удалён. Лицензия MIT проекта на них не распространяется.
- Семь текстур бумаги в `src/assets/local/papers` — сторонние материалы, лицензия приобретена командой. Кадрированы и сжаты. Лицензия MIT проекта на них не распространяется.

## ИИ-инструменты

В самом продукте ИИ не используется: страницы собирают детерминированные правила без языковой модели. ИИ помогал команде в разработке:

- Claude Code (Anthropic) — архитектура, движок правил, модули ввода, звука и архива, ревью и проверки.
- ChatGPT / Codex (OpenAI) — отрисовка скетчбука, композиции и правила раскладки страницы.
- ImageGen (OpenAI) — иллюстративные демо-кадры и вырезанные материалы скетчбука (перечислены выше).

## Сервисы и API

- iTunes Search API — поиск песен и официальные 30-секундные фрагменты, provided courtesy of iTunes.
- Open-Meteo — почасовая погода, CC BY 4.0.
- GitHub Pages — хостинг прототипа.
